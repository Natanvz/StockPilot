# Features

Current-behavior reference for each feature — what it does today, not why it was decided (that's in
[../decisions/](../decisions/)) or how it will be built (that's in [../plans/](../plans/)).

> Status: empty for now. A feature doc is added as each feature ships. Planned entries:

- **authentication** — sign-up, sign-in, sign-out, session handling.
- **products** — the CRUD API and the product list / detail behavior.
- **categories** — the categories collection and the admin CRUD screen.
- **dashboard** — the product table, filtering, sorting, pagination, and summary metrics.
- **search** — optional Meilisearch full-text search (off by default).
- **roles** — how admin vs viewer changes what a user sees and can do.

Group docs under subfolders as the set grows (e.g. `routes/`, `components/`, `systems/`).
